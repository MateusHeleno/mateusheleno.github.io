# Portfólio pessoal — Mateus Heleno

Portfólio estático em HTML e CSS, para publicação no GitHub Pages: https://mateusheleno.github.io/

## Arquivos

- `index.html` — página principal com estilos incorporados.
- `mateus-heleno-icone-mh-preto.svg` — marca no cabeçalho e favicon.
- `mateus-heleno-icone-mh-branco.svg` — símbolo na abertura.
- `mateus-heleno-logo-completa-branca.svg` — assinatura no contato.
- `mateus-heleno-logo-completa-preta.svg` — variante da marca disponível para futuras seções.

## Publicação

1. Extraia os arquivos e faça upload **de todos** na raiz do repositório `MateusHeleno/mateusheleno.github.io`.
2. Confirme o commit na branch `main`.
3. Em Settings → Pages, mantenha a publicação de `main` e `/(root)`.
4. Acesse o site e confira a logo e os links de GitHub e LinkedIn.

Não requer React, Tailwind, shadcn ou ferramentas de build. A fonte externa usa Google Fonts com fallbacks locais.

As descrições dos projetos distinguem entregas em andamento de iniciativas planejadas. Nenhum código ou dado interno da Cener é publicado.
